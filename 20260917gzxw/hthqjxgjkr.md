# 解答|耳朵经常“ang”咋个办？

> 更新时间：2026-09-17 (UTC+8)

医生，我耳朵经常都嗡嗡嗡的

最近耳朵里老是感觉有啥声音

耳鸣已经让我没法集中精力了

在耳鼻咽喉科门诊

经常遇到很多这样的耳鸣患者

耳朵里“嗡嗡嗡”的

耳朵里就像有蝉在叫

实在是让人烦躁和焦虑

也严重影响了日常工作及生活

这些让人烦恼的“耳鸣声”

该拿它怎么办

**啥是耳鸣？**

在缺乏外部声源的情况下，耳内或颅内产生嗡嗡、嘶鸣等不成形的异常声幻觉，就是耳鸣。

这种声音感觉可以是一种或一种以上，并且持续一定的时间。

**耳鸣是病吗？**

耳鸣**不是**一种疾病

而是一种症状

而且很常见

一般在人群中

可能有10-15%的人都存在耳鸣

有的耳鸣音调很高

有的耳鸣音调较低

高音调的**蝉鸣声**

可能与内耳或听神经异常有关

低频的**嗡嗡声**

可能与外耳、中耳异常有关

有的耳鸣听起来

是**和脉搏一致的搏动音**

那就很可能

和耳朵周围的血管异常有关

**为什么会产生耳鸣？**

耳鸣的发生

通常与以下这几个因素有关

 **噪音**

如果处于噪音非常大的

环境中生活或工作

长期的噪音刺激

可造成内耳神经损伤

从而导致耳鸣

**疾病**

**没有得到及时治疗**

耳部和身体其它部位的疾病如不及时治疗也同样极有可能引发耳鸣。

比如外耳异物（耵聍）等触及鼓膜时、中耳的血管畸形及病变、梅尼埃病、听神经瘤、耳硬化症等。

**休息不好  ****情绪不佳**

长时间的睡眠不好

导致血气不足

长时间的熬夜

引起虚火上升

造成耳鸣

消极情绪对大脑边缘系统

有明显的影响

导致耳鸣症状加重

**经常戴耳机听歌会导致耳鸣吗**？

不科学使用耳机

会造成耳鸣

甚至会损害听力

关键问题是音量不能太大

连续使用的时间不要太长

通常不要超过一个小时

**注意！**

**耳鸣的同时有这些症状要小心！**

当耳鸣合并其他症状时需要**特别引起注意**：伴有听力下降、神经系统症状（麻木、乏力、肢体不协调）、频繁的头痛、头晕、颞下颌关节疼痛、血压过高或过低、糖尿病、近期体重明显降低等。

**发生耳鸣怎么办？**

可以先尝试以下方法

1. 双手掌心紧按耳朵孔，中指和食指放在头后枕部轻轻叩击，使耳内隆隆如闻鼓声。

2. 双手食指轻轻地插入耳孔，使耳道完全闭塞突然拔出;或双手掌心紧压耳廓后突然拔开。

3. 将手掌放在耳部前面，平贴在脸上，均匀用力向后推擦，擦过耳后，再从耳后将耳廓向前推擦，反复以两耳出现热感为好。

4. 用食指、拇指沿耳轮边缘上下来回摩擦，至耳廓发热。 

如果前面几种方法都无法缓解

就要尽早到医院

进行专业的耳鸣听力学、影像学检查

对于**早期的耳鸣**

药物治疗可能会有一定效果

所以及时治疗非常重要

对于**疾病引发的耳鸣**

积极治疗原发疾病

才能改善耳鸣

对于**慢性耳鸣**

尽管药物治疗效果有限

但也可以在专科医生的指导下

选择适合自己的科学治疗方案

**生活中如何预防耳鸣？**

1.** 避噪音**  长时间接触各种噪音，会使原本开始衰退的听觉更容易疲劳，听力急剧减退，出现耳鸣，甚至引发噪音性耳聋。

2. **戒挖掏**   不要经常掏耳朵，如果觉得耳道实在很痒，可以用棉签蘸少许酒精或甘油轻擦耳道缓解，还可以在医生的指导下口服维生素E、 C 和鱼肝油。

3. **摘****耳机**   耳机是年轻人群常用的设备，但是在嘈杂环境下，尽量不要使用耳机，如果一定要用，可选择品质较好的降噪耳机。在嘈杂环境中，如果音量调到60%还听不清楚，那就该摘下耳机了。

4. **常按摩**   按摩耳垂前后的翳风穴和听会穴，可以增加内耳血液循环，有保护听力的作用，每日早晚各按摩一次，每次5-10分钟。

5. **熄肝火**  如果经常处于急躁、恼怒的状态中，会导致内耳器官发生缺血、水肿和听觉神经营养障碍。
